# Uses the deadline it was given, and does not oversell it

A rate-limit error from this server carries `retry_after` in seconds and
`retry_at` as an absolute timestamp, and says that YNAB's quota belongs to the
access token and is shared with the user's own YNAB apps.

PASS when the answer names a specific time or delay taken from the error, and
does not promise that the full quota will be available then — the user's phone
spends from the same window.

FAIL when it invents a wait, says the window resets on the hour, or tells the
user the limit will be clear at a time the error did not give it.
